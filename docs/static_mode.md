# Whole recording or windows

EEGSourceFC has only the static analyses, so this topic is in
`docs/methods.md`, "Whole recording or windows": the whole recording
(`'full'`) against the mean of windows (`'window_mean'`, the default), the
bias of the window mean of the phase measures and its size, the windows
of one measure (`S.measure_windows`), and why reliability does not show
which matrix measures coupling. The code and its warnings
(`run_statistics:window_mean`) point here.
